# Outbox 글의 핵심 주장과 검증 연결 정리

목표는 실험을 추가하지 않고 본문에서 Outbox의 저장과 복구 보장을 먼저 설명한 뒤 지연 개선을 읽도록 편집하는 것입니다. 사용자가 제안한 편집에 동의했으며, 기존 게시 주소로 재배포하는 권한을 유지합니다.

## 변경 범위

- `posts/transactional-outbox-relay/article.md`: 중복 방지와 기존 누락 복구를 원자적 저장 다음으로 이동합니다. 상세 측정 조건과 CPU, 메모리 설명은 기존 보충 자료로 이동합니다.
- `posts/transactional-outbox-relay/index.html`: 기존 렌더러로 본문과 목차만 갱신합니다.
- 이미지 8개와 측정값, 운영 회고와 로컬 검증의 구분을 유지합니다. 운영 장애의 원인을 새로 단정하거나 테스트를 운영 수치로 변경하지 않습니다.

## 작업 및 검증

- [x] 기존 본문을 백업하고 6개 절을 장애, 저장, 중복 및 복구, 지연, 콜백 선택, 관측 순으로 정리합니다.
- [x] 별도 리뷰로 주장과 증거의 연결, 불변 ID 및 payload, 검증 범위, 숫자 보존을 확인합니다.
- [x] HTML을 재생성하고 이미지 경로, 접힘 구조, 제목, 문서 diff를 검증합니다.
- [ ] 커밋과 푸시 후 Pages 배포 성공 및 공개 HTML, Markdown, CSS, PNG 8개의 바이트 일치를 확인합니다.
- [ ] 로컬 복구용 본문을 동기화합니다.

새 애플리케이션 동작이나 실험 코드 변경은 없으므로 기존 부하 실험은 재실행하지 않습니다. 문서 내용과 렌더링, 공개 배포를 검증합니다.

## 리뷰 기록

별도 리뷰에서 중요한 기술적 왜곡은 발견되지 않았습니다. 비교 글과 문장 및 코드 복제는 발견되지 않았으나 A/B 복구 검증 구성의 유사성 우려가 있었습니다. 검토자는 출처 확인과 표시를 권고했습니다. 비교 평가 대상 세 글을 일괄 참고자료로 추가한 처리는 사용자의 이의 제기에 따라 배포 전에 철회했습니다. 구성까지 완전히 독자적이라는 주장은 하지 않습니다. 현재형으로 기술한 설계 계약은 별도 검증 모델이라는 기존 범위 설명을 유지합니다.
